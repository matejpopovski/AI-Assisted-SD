## How it works

**Two hooks** registered in `.claude/settings.json`, both async:

1. **`UserPromptSubmit`** → `log_ai.py prompt`: reads the incoming prompt + session ID from stdin JSON and stashes it in `/tmp/claude_ai_prompts.json`, keyed by session ID.

2. **`Stop`** (fires when Claude finishes responding) → `log_ai.py stop`:
   - Skips if `stop_hook_active` is set (avoids re-triggering itself).
   - Pops the saved prompt for this session from the temp file.
   - Parses the session's JSONL transcript (`transcript_path`), extracting all user messages, every `tool_use` block (tool name + input), and the last assistant text block as the "final response."
   - Falls back to the transcript's first user message if the prompt wasn't captured via the `UserPromptSubmit` hook.
   - Renders a Markdown file to `ai_log/YYYY-MM-DD_HH-MM-SS_<8-char-session-id>.md` with three sections: User Prompt, Tools Used (human-readable bullet per tool call, e.g. `Bash: <cmd>`, `Edit: <path>`), and AI Summary
