# CLAUDE.md

This is your fork of the course's lectures repo — one repo for the whole semester. Each
`Lecture N - <Title>/` folder holds that week's in-class activity; `project/README.md` inside
it describes what you need to accomplish and how to verify it. See the root `README.md` for
the full workflow (updating your fork before each lecture, committing/pushing within 48 hours).

There is no build system or test suite at the repo root — each lecture's `project/` is a small,
self-contained piece of work with its own setup, described in its own `README.md`.
